About RetailRec India

A production-ready, deep learning-based personalized recommendation system engineered for Indian e-commerce, utilizing Neural Collaborative Filtering (NCF) with customer and item embeddings.

🚨 The Business Problem

E-commerce platforms across India manage thousands of items and diverse consumer segments. Manually identifying relevant products for every individual shopper is impossible. Generic popularity rankers fail because they recommend the same items to everyone, ignoring unique consumer preferences across clothing, electronics, and home furnishings.

💡 The Deep Learning Solution

Neural Collaborative Filtering (NCF) replaces linear matrix factorization dot products with non-linear neural network layers. By learning 32-dimensional dense latent vectors for customers and products, the model discovers non-linear purchase patterns and scores unseen candidate items to generate personalized Top-K recommendations.

📐 End-to-End System Architecture

From raw transaction records to interactive cloud web UI.

📦
Stage 1 • Data Source Ingestion
Authentic Indian E-Commerce Transaction Dataset
Madhav E-Commerce Dataset

Raw sales records sourced from authentic Indian retail operations: 500 multi-item orders (Orders.csv) and 1,500 granular transaction line items (Details.csv) spanning 19 Indian states and 336 individual consumers in 2018.

▼
🧹
Stage 2 • Preprocessing & Validation
Data Cleaning & Cross-Table Integration Pipeline
Strict Data Integrity

Performs schema casting, currency standardization (INR ₹), date normalization across Indian formatting, sub-category taxonomy verification (17 items across Clothing, Electronics, and Furniture), and referential consistency checks. Zero synthetic, random, or mock records.

▼
📊
Stage 3 • Matrix & Negative Sampling
Customer-Item Interaction Matrix & Holdout Partitioning
1,156 Interaction Pairs • 20.24% Density

Constructs sparse bipartite graph of 336 unique customers × 17 product sub-categories. Partitions data via chronological holdout split (80% train / 10% validation / 10% test) to prevent future-data leakage. Synthesizes negative unpurchased pairs at a verified 2:1 ratio strictly drawn from candidate items each customer never bought.

▼
🧠
Stage 4 • Deep Learning Core
Neural Collaborative Filtering (NCF) Dual-Embedding Architecture
17,569 Trainable Parameters

Non-linear collaborative filtering architecture replacing classical matrix factorization dot products with dense neural representation layers:

⚡ Deep NCF Layer Progression
Input → Embeddings → Concat → MLP → Probability
Customer Input & Embedding Embedding(336, 32) Maps discrete customer IDs into 32-dim dense latent representation
Product Input & Embedding Embedding(17, 32) Maps discrete sub-category IDs into 32-dim product feature space
▼ Concatenation Layer (64 Latent Dimensions) ▼
Dense Layer 1 + Regularization Dense(64, ReLU) + Dropout(0.20) Learns high-order non-linear customer-product interaction features
Dense Layer 2 + Regularization Dense(32, ReLU) + Dropout(0.20) Compresses feature representations, guards against overfitting
Output Prediction Layer Dense(1, Sigmoid) Generates predicted interaction score in range [0.0, 1.0]

⚡
Stage 5 • Backend Serving
High-Performance FastAPI REST Inference Engine
< 15ms Inference Latency

Artifacts (Keras model weights, customer encoders, catalog metadata) are loaded into memory once on application startup. Incoming prediction requests evaluate all unpurchased candidate products in parallel vector batches with sub-millisecond scoring, strictly returning top-K highest affinity items with fallback handling.

▼
💻
Stage 6 • Frontend Experience
Pure Vanilla JS Interactive Web Application
Zero Heavy Framework Overhead

Clean client-side architecture built with standard HTML5, CSS3, and modern Vanilla ES6+ JavaScript. Features responsive Chart.js data visualizations, interactive customer autocomplete search, dynamic Top-K ranking slider, order history exploration, and full production deployment compatibility for Render Cloud.
